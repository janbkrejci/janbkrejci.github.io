## Calendar

Month calendar (Monday first) with events. Month and weekday names follow the client locale. Previous/next fire navigateAction with the target month (and write a bound `month`); a click on an event fires openAction; a click on a day fires createAction.

| Prop | Type | Required | Default | Description |
|---|---|---|---|---|
| `createAction` | Action | no |  | Fired on a click on a day's empty area or its day number; the context gets `date` (YYYY-MM-DD) added. |
| `events` | DataBinding \| object[] | no |  | Events of the calendar, in array order within each day. A list or a binding to a data path. Invalid entries and duplicate ids (after the first) are not shown. Default []. |
| `maxVisible` | number | no | `3` | Events shown per day before a "+N" button opens the full list of that day. Default 3. |
| `month` | DynamicString | no |  | Shown month, YYYY-MM. Default: the current month; an invalid value also shows the current month. When bound to a path, the previous/next buttons write the new month there (two-way). |
| `navigateAction` | Action | no |  | Fired by the previous/next buttons; the context gets `month` (the target YYYY-MM) added. When `month` is bound it is written first. Without it and with a literal `month` the buttons are disabled. |
| `openAction` | Action | no |  | Fired on an event click; the context gets `event` (the event id) added. Without it the event chips are disabled. |

**Outputs to bind to a path (C1):** `month`. A literal value is never written back; bind it, for example `{"path": "/ui/<id>/month"}`, and set the initial value with updateDataModel.

**Actions and their context (X5):**

- `createAction`: Fired on a click on a day's empty area or its day number; the context gets `date` (YYYY-MM-DD) added.
- `navigateAction`: Fired by the previous/next buttons; the context gets `month` (the target YYYY-MM) added. When `month` is bound it is written first. Without it and with a literal `month` the buttons are disabled.
- `openAction`: Fired on an event click; the context gets `event` (the event id) added. Without it the event chips are disabled.

**Item scope (C2):** `openAction` resolve relative paths in their context against the clicked item of `events`, so `events` must be bound to a path (for example `{"path": "/events"}`), never a literal list (R13). `{"path": "id"}` then reads the item's id.

## TextField

A labelled text input: single line, multi-line, number as text, or password. Writes the bound value on every keystroke and fires changeAction when the user commits a change (blur or Enter).

| Prop | Type | Required | Default | Description |
|---|---|---|---|---|
| `autofocus` | boolean | no | `false` | Focuses the control on mount and when its Form tab becomes active. |
| `changeAction` | Action | no |  | Action fired after a committed user change. The context gets the new `value` added. |
| `disabled` | DynamicBoolean | no | `false` | Disables the control. Inherited from an ancestor Form. Bind it to toggle at runtime. |
| `enterAction` | Action | no |  | Action fired on Enter instead of enterBehavior. The context gets the current `value` added. |
| `enterBehavior` | "submit" \| "next" \| "none" | no |  | What Enter does: submit the enclosing Form, move focus to the next field, or nothing. Defaults to submit inside a Form and none outside. |
| `error` | DynamicString | no |  | Server error for this field. Bind it to a path in the errors part of the data model. |
| `escapeAction` | Action | no |  | Action fired on Escape after open popups are closed. The context gets the current `value` added. Escape never clears the field. |
| `excludeFromSubmit` | boolean | no | `false` | When true, the Form leaves this field's path out of its submitted data. |
| `hideLabel` | boolean | no | `false` | Hides the visible label but keeps its slot for row alignment; the label becomes the aria-label. |
| `hint` | DynamicString | no |  | Helper text shown under the control when no error is shown. |
| `inputType` | "text" \| "email" \| "tel" \| "url" \| "search" | no | `"text"` | HTML input type for variant shortText; selects the matching keyboard on mobile devices. |
| `label` | DynamicString | yes |  | The text label for the input field. |
| `maxLength` | number | no |  | Maximum number of characters the user can type. |
| `placeholder` | DynamicString | no |  | Placeholder text shown while the control is empty. |
| `readOnly` | DynamicBoolean | no | `false` | Shows the value without allowing edits, writes or actions; the control stays focusable. Inherited from an ancestor Form. |
| `required` | boolean | no | `false` | Marks the field as required: shows an asterisk, sets aria-required and adds an implicit check that the value is not empty. Literal only. |
| `rows` | number | no | `3` | Number of visible text rows for variant longText. |
| `selectAllOnFocus` | boolean | no |  | Selects the whole text when the field gains focus. Defaults to true, and to false for variant longText. |
| `validationRegexp` | string | no |  | A regular expression used for client-side validation of the input. A non-empty value that does not match shows an 'Invalid format' error after blur. |
| `value` | DynamicString | no | `""` | The value of the text field. Bind it to a data path: every keystroke is written there. |
| `variant` | "longText" \| "number" \| "shortText" \| "obscured" | no | `"shortText"` | The type of input field to display: shortText (single line), longText (multi-line; Enter inserts a newline, Ctrl/Cmd+Enter runs the Enter behaviour), number (single line with a numeric keyboard; still writes a string, use NumberField for typed numbers), obscured (password with a show/hide toggle). |

**Outputs to bind to a path (C1):** `value`. A literal value is never written back; bind it, for example `{"path": "/ui/<id>/value"}`, and set the initial value with updateDataModel.

**Actions and their context (X5):**

- `changeAction`: Action fired after a committed user change. The context gets the new `value` added.
- `enterAction`: Action fired on Enter instead of enterBehavior. The context gets the current `value` added.
- `escapeAction`: Action fired on Escape after open popups are closed. The context gets the current `value` added. Escape never clears the field.

**Minimal example:**

```json a-2-ui
[
  {
    "version": "v0.9.1",

    }
  },
  {
    "version": "v0.9.1",
    "updateComponents": {
      "surfaceId": "textField",
```

## Toaster

Notification toasts driven by a bound data model array. Use at most one per surface; a second one renders nothing.

| Prop | Type | Required | Default | Description |
|---|---|---|---|---|
| `duration` | number | no | `4000` | How long each toast stays, in ms, before it closes itself. Default 4000. |
| `items` | DataBinding | yes |  | Required. Binding to an array of toasts [{id: string\|number, text: string, title?: string, tone?: 'neutral'\|'info'\|'success'\|'warning'\|'danger'}] that the client reads and writes. Push an entry to show a toast. When its timer runs out or the user closes it, the client writes back the array without that id. Entries without a string or number id are ignored. When several entries share an id, only the first one is shown. |
| `position` | "top-right" \| "top-center" \| "bottom-right" \| "bottom-center" | no | `"bottom-right"` | Screen corner or edge where toasts stack. Default bottom-right. |

**Outputs to bind to a path (C1):** `items`. A literal value is never written back; bind it, for example `{"path": "/ui/<id>/items"}`, and set the initial value with updateDataModel.

**Minimal example:**

```json a-2-ui
[
  {
    "version": "v0.9.1",
    "createSurface": {
      "surfaceId": "toaster",
      "catalogId": "https://janbkrejci.github.io/TSWebUI-a2ui/catalogs/tswebui/v1/catalog.json"
    }
  },
  {
    "version": "v0.9.1",
    "updateComponents": {
      "surfaceId": "toaster",
      "components": [
        {
          "id": "root",

          "items": {
            "path": "/toasts"
          }
        }
      ]

  },

    "updateDataModel": {
      "surfaceId": "toaster",

          "id": 1,
          "text": "Changes saved."
        }
      ]
    }
  }
```


## Window

A floating window in the window layer with a title bar (minimize, maximize or restore, close), two-way open and state, and modal: true for agent-opened dialogs. Ctrl+F6 moves focus to the next window, Tab stays inside the window. One surface per window is the recommended pattern.

| Prop | Type | Required | Default | Description |
|---|---|---|---|---|
| `autoFit` | boolean | no | `true` | Fit the window height to its content when it opens. Default true. |
| `child` | ComponentId | yes |  | ID of the component shown inside the window. To show several components, wrap them in a Column. |
| `closable` | boolean | no | `true` | Show the close button in the title bar. Default true. |
| `closeAction` | Action | no |  | Action fired when the user closes the window (close button, Escape on a modal window), after open=false is written. Adds nothing to the action context. Not fired when the agent closes it. |
| `height` | number | no | `300` | Initial height in pixels. Default 300. |
| `minHeight` | number | no | `100` | Minimum height in pixels. Default 100. |
| `minWidth` | number | no | `200` | Minimum width in pixels. Default 200. |
| `modal` | boolean | no | `false` | Dims the window layer behind the window, traps focus inside it and closes it on Escape. Use it for dialogs the agent opens without a trigger. Default false. |
| `open` | DynamicBoolean | no | `true` | Two-way: bind it to a path ({"path": "/x"}) to show or hide the window by writing true or false; the close button (and Escape for a modal window) writes false, then fires closeAction. Default true. |
| `state` | DynamicString | no | `"normal"` | Two-way window state: "normal", "minimized" or "maximized". The title buttons and a title double-click write it when bound to a path. Default "normal". |
| `title` | DynamicString | no | `""` | Text in the title bar. When empty, a visually hidden title (accessibility.label or a localized 'Window') names the window for screen readers. Default empty. |
| `width` | number | no | `400` | Initial width in pixels. Default 400. |
| `x` | number | no | `100` | Initial left edge in pixels. Default 100. When neither x nor y is given, each new window in the layer is offset by 24 px down and right (cascade). |
| `y` | number | no | `100` | Initial top edge in pixels. Default 100. When neither x nor y is given, each new window in the layer is offset by 24 px down and right (cascade). |

**Outputs to bind to a path (C1):** `open`, `state`. A literal value is never written back; bind it, for example `{"path": "/ui/<id>/open"}`, and set the initial value with updateDataModel.

**Actions and their context (X5):**

- `closeAction`: Action fired when the user closes the window (close button, Escape on a modal window), after open=false is written. Adds nothing to the action context. Not fired when the agent closes it.

**Children:** `child` (component ids).

**Minimal example:**

```json a-2-ui
      "surfaceId": "window",

    }
  },
  {
    "version": "v0.9.1",
    "updateComponents": {
      "surfaceId": "window",
      "components": [
        {
          "id": "root",
          "component": "Window",

          "id": "body",

        }
```
